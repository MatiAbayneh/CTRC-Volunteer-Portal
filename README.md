# CTRC-Volunteer-Portal
Mobile-friendly volunteer portal for CTRC, built by Blueprint Boulder.
## Core Features

### Broadcast Alerts
Allow CTRC staff to send important announcements to volunteers.

Potential delivery methods:
- SMS/text messages
- Web push notifications
- In-app notifications

### Timesheets
Allow volunteers to access and complete their weekly hours through a
mobile-friendly interface integrated with Neon One's timesheet functionality.

### News Bulletin Board
Provide volunteers with a centralized location for:
- Upcoming events
- Important announcements
- Volunteer information
- Helpful resources

### Internal Volunteer Communication
Allow volunteers to communicate without sharing personal phone numbers
or email addresses.

Primary use case:
- Finding another volunteer to cover a shift

### Metrics
Potential administrative dashboard for volunteer activity and other
organizational statistics.

This is a secondary feature pending additional client requirements.
